# Web Calendar

基于原生 JavaScript + Vite 的日历组件，零运行时依赖。

## 功能

- **月视图**：按真实日历结构展示 6 行 × 7 列（周一起始），当前月与其他月日期区分样式，支持上一月 / 下一月 / 回到今天；点击日期可获取对应日期并新建事件；移动端日期数字放大、事件以圆点展示保证可读性。
- **周视图**：24 小时时间轴，当前时刻红线指示。
- **拖拽与调整时间**：基于 Pointer Events（鼠标/触屏通用），月视图可跨日期拖拽事件；周视图可拖动改时间（15 分钟吸附，支持跨日）并拖拽底部手柄调整时长；拖拽时显示幽灵卡片与落点高亮，按 Esc 取消并恢复原状；更新失败时数据不写入、视图自动恢复。
- **事件详情面板**：点击事件打开侧边面板，展示标题、日期、时间、描述；支持编辑与删除（删除二次确认）。
- **数据规则**：每个事件拥有唯一 ID；时间统一使用 `YYYY-MM-DDTHH:mm` 格式；严格校验非法日期（如 2 月 30 日）；标题不能为空；结束时间必须晚于开始时间。
- **持久化**：事件保存在 `localStorage`。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run preview  # 预览构建产物
```

## 失败回滚测试

浏览器控制台执行 `__simulateNextWriteFail()` 后，下一次拖拽更新 / 编辑保存 / 删除会失败，
可验证：拖拽与表单数据均恢复原状，并弹出错误提示。

## 代码结构

- `src/dateUtils.js` 日期网格、格式统一、非法日期校验
- `src/store.js` 事件存储（localStorage 持久化、异步 API、写入前校验、订阅通知）
- `src/drag.js` Pointer Events 拖拽原语与视觉反馈
- `src/monthView.js` 月视图
- `src/weekView.js` 周视图
- `src/eventPanel.js` 详情 / 编辑 / 新建面板（删除二次确认）
- `src/toast.js` 错误提示
- `src/main.js` 工具栏、视图切换、拖拽更新失败回滚
